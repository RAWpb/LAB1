Circle - реализация вычисления параметров окружности: длинны окружности, площади круга, площади кругового сектора.
    Считывание значений радиуса(r) и угла дуги в градусах(s) с клавиатуры
    Вычисления значений по формулам:
    Формула для вычисления длинны окружности — 2пr
    Формула для вычисления площади круга — пr*r
    Формула для вычисления площади кругового сектора — пr*r / (360 / s)
    Вывод результата

Trapec - реализация вычисления параметров трапеции: периметр, площадь, средняя линия.
    Считывание значений сторон и высоты с клавиатуры
    Вычисления значений по формулам:
    Формула для вычисления периметра: a + b + c + d
    Формула для вычисления площади: ((a + b)/2) * h
    Средняя линия: (a + b) / 2
